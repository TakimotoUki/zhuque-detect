## 已处理的主要问题

| 原有问题 | 处理 |
|---|---|
| 用 Host 表示“本机”可能影响令牌豁免；跨端口/任意来源不够严格 | 实际监听和对端均为回环才豁免；校验 Host、来源和端口，非回环必须令牌；允许顶层 HTML 导航，跨站 API 仍拒绝 |
| 更改候选 endpoint 的连通性测试可能发送已保存 Key | 不同上游测试需显式提供 Key；远程仅 HTTPS，禁止内嵌凭据与重定向 |
| 缓存可跨 Key、上游或原始响应选项混用，并共享可变对象 | 隔离缓存范围、复制对象；命中重新记历史并显示零计费用量 |
| fetch 的计时器提前结束，响应体停顿无法超时 | 覆盖完整响应读取，8 MiB 响应上限，清理 abort 信号 |
| 不完整成功响应可能被解释为人工文本；整体/段落标签约定混用 | 校验响应与比例；整体用官方 `labels_ratio`，稀疏段落不覆盖整体占比 |
| 长文失败时重发成功分块，已成功但后续失败的用量漏记 | 只重试失败块，各成功请求立即记账；保持原文空白和 emoji、全局位置 |
| 同账号多 Key 可能被误当独立配额；无可用池项回退到另一把单 Key | 加入 account 分组冷却，池全不可用时返回明确错误 |
| 小于 1% 的历史比例被放大；只截正文仍在 segments 中保存全文 | 区分百分比与 ratio，正文限制同时移除分段副本；处理坏 JSON 行 |
| CSV 前置空白可绕过公式防护 | 对前置空白后公式起始符做保护 |
| 同时运行 HTTP、CLI、MCP 会覆盖存储；今日上午校准漏算 | 文件事务锁与原子写入；校准包含今日记录，1–31 日账期对短月截取 |
| MCP 未初始化也可访问工具，被拒客户端仍能读资源 | 初始化状态校验与统一限制，完整 JSON-RPC 输入校验 |
| stdin EOF 立即退出，异步检测结果丢失 | 等待已接受调用完成；错误日志只输出 stderr |
| Codex 配置误用 JSON/本机 Node 绝对路径；Windows JSON 转义不足 | 原生 Codex CLI/TOML，默认 `node` 依靠 PATH，按平台安全引用路径 |
| 启动器旧 PID 可能结束无关进程，Windows 空格路径及中文编码出错 | PID + 进程启动时间 + 命令验证；参数引号、ASCII cmd、UTF-8 BOM PowerShell |
| 网页导出无法带远程令牌、重复提交、清空后迟到结果重新出现 | 经带令牌 fetch 导出，禁止并发检测，用请求代次忽略清空后的显示 |
| 平台副本/旧打包分支冗余，能够夹带 token 与本机配置 | 一份核心 + 发布白名单，明确禁止嵌入凭据与复用非空输出目录 |

没有发现隐藏的遥测、额外上传目的地、挖矿/驻留下载或混淆执行代码。运行时网络目的地是腾讯朱雀默认 API 或用户自行配置的 endpoint；浏览器打开本机页面、文档和控制台。官网为静态页面，不接收 Key。可配置网络地址和本机路径是公开功能，不能把它们全部删除。Node 18/20 已不作为支持基线，使用 Node 22+。

## 验证方式

`node src/selftest.mjs` 是现有功能回归；`node tests/security.test.mjs` 用本机假上游和合成凭据检查安全与边界；`node tests/site.test.mjs` 验证系统主题、手动覆盖/持久化、返回自动模式与存储受限；`node tests/platform.test.mjs` 在原生 macOS/Windows 运行启动、改端口后的身份识别和停止；`node src/webcheck.mjs` 检查网页脚本与 DOM 合约。测试状态目录都在临时目录，不读取真实 token.txt，不发送付费腾讯请求。

MCP 回归以实际子进程 stdio 执行 Codex clientInfo 的 initialize → tools/list → tools/call；包括立即 EOF、初始化前调用、拒绝客户端资源读取、复制到中文/空格路径并从无关 cwd 启动。这个测试证明本服务的协议与路径处理；客户端实际 PATH、信任设置、第三方客户端版本和真实腾讯账号状态仍需用户本机检查。并未把 mock 分数当真实降幅。

GitHub Actions 在 macOS、Windows、Ubuntu 与 Node 22/24 上执行相同检查、原生启动器测试和双平台打包；每次具体结果以该提交的 Actions 记录为准。Linux 跳过原生桌面启动器测试。网站使用指定 Chrome 检查桌面两种主题和手机宽度，流程分数标注为演示。

## 保留边界

- 腾讯官方文档明确整体占比 `labels_ratio` 为 0 人工、1 AI、2 疑似 AI；段落 `segment_labels` 的 1/2 约定沿用项目已有实际响应样本，官方示例未完整枚举。上游变更需重新对照；未知段落标签按疑似处理。位置按 JavaScript UTF-16，若上游位置与文本不符，应核对片段再改写。
- 默认保存完整历史，原文会发到腾讯。配置备份仍可含旧 Key；删除当前配置不能消除备份。Windows 文件 ACL 由用户目录控制。
- 客户端名字可模拟，名单不构成身份认证。具备本机用户权限的程序可以访问该用户的 Key。HTTP 服务不适合作为公共多租户服务；远程部署还需要自行配置 TLS 与访问网络。
- 本地用量并非云端余额；其他程序的消费不自动同步，混合账号汇总也不能当成某个账号余额。成功调用但存储写失败会在结果中提示本地统计/历史不完整。
- 同步存储锁超时会失败，不抢占遗留锁；崩溃后需先确认相关进程停止再手动清理。不针对本机已具备写权限的恶意用户提供隔离。
- 自动审查与 mock 回归不证明真实模型可达、改写一定达到目标、全部客户端版本兼容，或不存在所有未来风险。
